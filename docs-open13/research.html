How it works

What is a long-context decision model?

Decision models are AI models that evaluate supplied context against defined questions and return structured answers. They excel when the deep reasoning or nuanced outputs of a frontier LLM are not required.

DimensionsLanguage model
OutputA choice, score, or labelOpen-ended text
Answer spaceFixed, defined up frontUnbounded
InferenceSecondsMinutes for the same task
Parsing needsNone. Structured output your code uses directlyParse and validate free text
Best atRouting, ranking, classifying, yes/no callsReasoning, writing, open-ended work
Weak atOpen-ended generationFast, repeated, structured calls
Place in agentThe decision points: route, filter, scorePlanning and generation

The subquadratic breakthrough.

Today's transformer-based LLMs waste compute by processing every possible relationship between tokens, but only a small fraction of these relationships matter. (This is called “quadratic scaling.”)

SubQ is built differently. Using a proprietary algorithm called Subquadratic Sparse Attention (SSA), it isolates the tokens and relationships that matter, ensuring compute is used efficiently.
